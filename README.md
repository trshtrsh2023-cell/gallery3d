# معرض الفوتوغرافيا الافتراضي — جمعية الثقافة والفنون بالطائف

## خطوات التشغيل
1. `npm install`
2. انسخ `.env.example` إلى `.env.local` وعبّئ قيم Supabase الحقيقية.
3. نفّذ `supabase_setup.sql` كاملاً في Supabase → SQL Editor.
4. أنشئ Storage bucket باسم `gallery-photos` واجعله Public (من Storage → New bucket).
5. أنشئ أول حساب أدمن:
   ```bash
   node -e "console.log(require('bcryptjs').hashSync('كلمة_المرور_هنا', 10))"
   ```
   ثم في Supabase SQL Editor:
   ```sql
   insert into admins (username, password_hash) values ('admin', 'الهاش_الناتج_هنا');
   ```
6. `npm run dev` للتجربة محلياً، أو ادفع المشروع لـ Vercel وأضف متغيرات البيئة هناك.

## الصفحات
- `/` — المعرض نفسه (إدخال اسم الزائر ثم الدخول، ورابط صغير بالزاوية العلوية اليسرى لدخول الإدارة)
- `/admin/login` — تسجيل دخول الإدارة
- `/admin/dashboard` — رفع/حذف/إعادة ترتيب اللوحات، وسجل الزوار

## ما تم إصلاحه في هذه النسخة
- اتجاه حركة WASD كان معكوساً (W يرجع للخلف بدل الأمام، وA/D معكوسين أيضاً) — تم تصحيحه بحساب اتجاه "الأمام" و"اليمين" الصحيحين من زاوية الكاميرا.
- الـ CSS الخاص بلوحة المعلومات الزجاجية وشاشة العرض الكامل كان مفقوداً من نسخة Next.js السابقة.
- نقرة الماوس كانت تُطلق فتح الصورة بالخطأ أثناء السحب للنظر حول الغرفة.
- زر "رجوع" من وضع ملء الشاشة لم يكن يصل لمتغيّر التحكم الفعلي فيتجمّد التحكم بعد أول نقرة على صورة.
